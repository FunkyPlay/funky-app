# Funky Launcher — mobile app

PWA + Telegram Mini App for FunkyPlay modlists (Neon Nights, Nova Nights, Atomic Nights). RU/EN.
Plain HTML/CSS/JS, no build step. Data: `catalog2.json` from [FunkyPlay/FunkyLauncher](https://github.com/FunkyPlay/FunkyLauncher), `data/*.json` here.
No keys or secrets in this repository. License: GPL-3.0.
